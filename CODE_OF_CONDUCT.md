# Community Code of Conduct

## Our standard

We are committed to a respectful, inclusive, and safety-first community.

Expected behavior:

- Be respectful and constructive.
- Treat all members fairly.
- Communicate in a professional and non-abusive way.

Unacceptable behavior:

- Harassment, hate, threats, intimidation, or abuse.
- Personal attacks, discrimination, or demeaning language.
- Encouraging illegal driving or risky behavior.
- Requests for, or promotion of, police reporting or police avoidance features.
- Misuse of location-related features in ways that endanger others.

## Responsible use of location features

- Use location features responsibly and with respect for privacy.
- Do not use community tools for stalking, tracking, or unsafe conduct.

## Reporting inappropriate behavior

If you experience or witness inappropriate behavior, report it privately to project maintainers/admins.

- Do not file public issues for Code of Conduct incidents.
- Conduct contact: **conduct contact to be added**.

## Enforcement

Maintainers and admins may moderate content, limit participation, or restrict access when behavior violates this code of conduct or community safety rules.
