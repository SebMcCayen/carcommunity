# Apple trust anchor

`AppleRootCA-G3.cer` is Apple's public Apple Root CA - G3 certificate, used by
the App Store Server Library to validate StoreKit signed transaction chains.

- Source: <https://www.apple.com/certificateauthority/AppleRootCA-G3.cer>
- SHA-256: `63343abfb89a6a03ebb57e9b3f5fa7be7c4f5c756f3017b3a8c488c3653e9179`

Do not replace this file without checking the subject, issuer, fingerprint and
Apple's current App Store Server Library guidance.
